# Online Reservation System

A Java Swing and SQLite JDBC based Online Reservation System developed as part of the Oasis Infobyte Java Internship.

## Features

- User login authentication
- Train number validation
- Automatic train name display
- Ticket booking
- Automatic PNR generation
- Reservation details retrieval using PNR
- Ticket cancellation with confirmation
- Input validation
- SQLite database integration

## Technologies Used

- Java
- Java Swing
- JDBC
- SQLite
- Maven
- IntelliJ IDEA

## Default Login

Username: `admin`

Password: `admin123`

## How It Works

1. Login using valid credentials.
2. Enter passenger and journey details.
3. Select the class type.
4. Book the ticket and receive a unique PNR.
5. Use the PNR to retrieve reservation details.
6. Cancel the ticket after confirmation.
